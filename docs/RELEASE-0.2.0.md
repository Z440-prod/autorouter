# AutoRouter 0.2.0 preview

This source preview introduces a shared, project-scoped MCP service and native integration packages for multiple coding agents. It preserves the optional native Codex patch. Linux smoke tests cover native Codex, Gemini CLI, OpenCode 1.x and Cline CLI registration. Claude Code plugin loading and MCP connection were verified. Authenticated Claude execution is pending. Model recommendations in the shared service use operator-supplied host catalogs. The native Codex adapter owns automatic execution switching.

See the installation guide for setup, upgrades and rollback. The release contains source and manifests, with host binaries installed separately.
