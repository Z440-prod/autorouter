# Task handoffs

The optional Codex patch can change the underlying model at supported sampling boundaries. The native thread presents confirmed selection in its own runtime state. Pending tools and approvals belong to the host.

Portable adapters can save a concise snapshot with `checkpoint_save` if the project grants writes to that host. Reuse the same task ID with `checkpoint_get` in another authorized client. Describe completed operations, verification evidence and pending work in the summary. Check the working tree and external receipts before resuming a side effect.
