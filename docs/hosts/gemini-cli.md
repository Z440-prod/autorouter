# Gemini CLI

Run `autorouter install --target gemini-cli` from the approved project in an interactive terminal. Review Gemini's workspace trust and extension prompts. The local extension provides MCP and the project-context skill. Run `gemini extensions list` and `gemini mcp list` to confirm registration. Launch Gemini normally and choose models in its own interface. [Gemini extension reference](https://geminicli.com/docs/extensions/reference/)
