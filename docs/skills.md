# Skills

AutoRouter ships a single project-context skill. Its native packaging is shared across Claude Code and Gemini CLI. Use `--skill /path/to/SKILL.md` with `autorouter workspace` for other reviewed skills. Clients can discover approved names and read the selected file via MCP.

Ponytail covers maintaining simple changes. Agent Skills covers engineering workflow. ECC supplies selected specialist guidance. Obsidian Skills supports note formats. CLI-Anything supplies CLI automation where useful. REA handles authorized specialist analysis. Install optional packages from their respective upstreams and preserve existing host registrations and trust controls.
